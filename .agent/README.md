## 💡 Полезные советы

### При отладке SQL запросов
- Используйте `postgres-irk-migr` для тестирования запросов напрямую
- Копируйте SQL из `monitors.sql_query` и выполняйте
- Проверяйте права доступа пользователя `tomcat`

### При проблемах с правилами
- Всегда проверяйте `is_active = 1`
- Проверяйте `cooldown_seconds` - может быть слишком большой
- Смотрите `condition_type` и `condition_value`

### При отладке веб-интерфейса
- Проверьте, запущен ли сервер на порту 8090
- Откройте http://localhost:8090/docs для Swagger UI
- Используйте curl для тестирования API

### При работе с логами
- Используйте `tail -f logs/app.log` для реального времени
- Фильтруйте по ключевым словам: `grep -i error logs/app.log`
- Проверяйте timestamp для корреляции с событиями
