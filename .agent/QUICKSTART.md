## ❓ Что-то не работает?

### MCP серверы не видны в Claude Desktop
1. Убедитесь, что перезапустили Claude Desktop
2. Проверьте файл конфигурации:
   ```bash
   cat ~/Library/Application\ Support/Claude/claude_desktop_config.json
   ```

### База данных пустая или не найдена
1. Запустите приложение: `python main.py`
2. БД создастся автоматически
3. Проверьте: `ls -lh data/notifications.db`

### Приложение не запускается
1. Проверьте логи: `tail -100 logs/app.log`
2. Проверьте config.yaml
3. Убедитесь, что установлены зависимости: `pip install -r requirements.txt`
